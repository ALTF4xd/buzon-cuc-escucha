# Buzón CUC Escucha - Facultad de Ingeniería

Micrositio web para recopilar sugerencias e iniciativas de mejora académica y estudiantil en la Universidad de la Costa (CUC).

## Tecnologías utilizadas

- HTML5 para el marcado semántico y accesible.
- CSS3 para estilos responsivos.
- Git para control de versiones y trazabilidad.
- GitHub para colaboración, ramas y Pull Requests.
- Netlify para despliegue continuo con HTTPS.
