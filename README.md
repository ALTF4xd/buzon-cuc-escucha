# Buzón CUC Escucha - Facultad de Ingeniería

Micrositio web institucional diseñado para recopilar propuestas, inquietudes e iniciativas de mejora académica por parte de la comunidad estudiantil de la Universidad de la Costa (CUC).

Este proyecto forma parte de la evaluación práctica de la asignatura **Buenas Prácticas de Desarrollo de Software**, evidenciando un flujo completo de control de versiones con Git, trabajo colaborativo en GitHub y despliegue continuo en Netlify.

---

## 🚀 Acceso en Vivo y Recursos

* **Sitio Web en Producción (Netlify):** [https://buzon-cuc-escucha-cuc.netlify.app](https://buzon-cuc-escucha-cuc.netlify.app)
* **Repositorio en GitHub:** [https://github.com/ALTF4xd/buzon-cuc-escucha](https://github.com/ALTF4xd/buzon-cuc-escucha)

---

## 🛠️ Tecnologías y Herramientas

* **HTML5:** Marcado semántico y accesible para la estructura del formulario (`index.html`).
* **CSS3:** Maquetación responsiva con paleta institucional CUC (`css/styles.css`).
* **Git:** Control de versiones local mediante consola Git Bash.
* **GitHub:** Alojamiento remoto, bifurcación en ramas (`feature branches`) y flujo de integración mediante Pull Requests.
* **Netlify:** Despliegue continuo (CI/CD) con aprovisionamiento automático de certificados SSL/HTTPS.
